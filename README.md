# ТехУчёт

Многостраничный сайт компании по сопровождению регистрационных действий с самоходной техникой.

## Локальный запуск

```powershell
npm run build
npm run check
npm run dev
```

После запуска сайт доступен по адресу `http://127.0.0.1:8765/`.

## Настройки

Контакты, страницы услуг, списки документов и настройки интеграций находятся в `src/data.mjs`. Команда `npm run build` создаёт статические страницы и клиентский `site-config.js`.

- `yandexMetrikaId` нужно заполнить реальным ID счётчика перед запуском рекламы.
- Формы отправляются через одобренный владельцем сервис FormSubmit и показывают успех только после ответа сервера `{ "success": true }`.
- Получатель всех заявок: `jobstat@bk.ru`. В клиентском коде нет SMTP-паролей, API-ключей или токенов.
- Production URL задаётся одной константой `SITE_URL` в `src/data.mjs`. Текущее значение: `https://tehuchet24.ru`.
