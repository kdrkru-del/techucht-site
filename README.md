# ТехУчёт — Корпоративный сайт

Федеральный сервис по регистрации самоходной техники по всей России.

## Описание

Одностраничный корпоративный сайт компании «ТехУчёт».  
Технологии: чистый HTML5 + CSS3 + Vanilla JavaScript (без фреймворков).

## Структура файлов

```
techucht-site/
├── index.html   — разметка всех секций сайта
├── style.css    — дизайн-система, стили, адаптив
├── script.js    — анимации Canvas, форма, геолокация
└── README.md
```

## Функционал

- 🎬 **Canvas-анимация** — анимированная сцена с экскаватором на первом экране
- 📍 **Автоопределение региона** — через IP-геолокацию (ipapi.co)
- 📋 **Полный список регионов РФ** — все 85 субъектов в формах
- 📱 **Адаптивный дизайн** — mobile-first, оптимизирован для Яндекс.Директ трафика
- ✨ **Анимации** — счётчики, scroll-reveal, hover-эффекты
- 🌑 **Тёмный индустриальный стиль** — glassmorphism, жёлтые акценты

## Секции

1. **Header** — прозрачная шапка, sticky при скролле
2. **Hero** — Canvas-анимация с техникой + форма заявки справа
3. **Статистика** — анимированные счётчики
4. **Услуги** — 6 карточек услуг
5. **Как мы работаем** — 5-шаговый процесс
6. **Стоимость** — 3 тарифных плана
7. **FAQ** — аккордеон с 6 вопросами
8. **Форма заявки** — полная форма + контакты
9. **Footer** — навигация, контакты, копирайт

## GitHub Pages

После пуша в репозиторий — перейдите в **Settings → Pages**,  
выберите ветку `main`, папку `/ (root)` и сохраните.

Сайт будет доступен по адресу:  
`https://YOUR_USERNAME.github.io/techucht-site/`

## Настройка контактных данных

Замените в `index.html`:
- `8 800 123-45-67` → реальный федеральный номер
- `info@techucht.ru` → реальный email

## Отправка форм

Для реального приёма заявок замените в `script.js` функцию `submitForm` —  
добавьте отправку на ваш backend или используйте сервис [FormSpark](https://formspark.io) / [Formspree](https://formspree.io).
